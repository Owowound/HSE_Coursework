# Содержание репозитория 
Данный репоиторий представляет собой текст программы для 2D action игры с элементами rpg под названием Elementals.

---
# Использованные технологии
- Игровой движок Unity
- Язык программирования C#
- Visual Studio в качестве IDE

---
# Ссылка на репозиторий с полнофункциональным пототипом игры
Билд игры находится по ссылке: https://github.com/Owowound/Elemental_Build

---
# Структура
```plaintext
- Assets
  Папка содержит все ресурсы проекта.
- Packages
  Папка содержит информацию о зависимостях в проекте.
- ProjectSettings
  Папка содержит настройки проекта.
- .gitignore
  Файл для исключения ненужных файлов при добавлении в github.
- .vsconfig
  Файл конфигурации, используемый Visual Studio.
